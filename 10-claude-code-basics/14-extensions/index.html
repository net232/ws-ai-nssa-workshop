    1-4. 확장: Skill · Subagent · MCP · Hook¶

    목표¶

    • 네 가지 확장 방식이 각각 어떤 문제를 푸는지 구분합니다.
    • starter kit에 들어 있는 skill, subagent, MCP 서버, hook을 확인하고 동작시켜 봅니다.

    1. 무엇을 언제 쓰는가¶

    확장 위치 언제 컨텍스트에 들어오나 이럴 때 씁니다 이 워크숍의 예
    CLAUDE.md 저장소 루트 항상 모든 작업에 적용할 짧은 규칙 리전·태그·삭제 규칙
    Skill .claude/skills/<이름>/SKILL.md 설명(description)만 항상, 본문은 필요할 때 반복되는 절차·템플릿·체크리스트 net-test-plan (테스트 계획서)
    Subagent .claude/agents/<이름>.md 호출할 때, 별도 컨텍스트에서 결과만 받으면 되는 조사, 독립 리뷰 net-reviewer
    MCP 서버 .mcp.json, claude mcp add 도구 목록으로 외부 시스템·데이터 연결 AWS Knowledge(문서), AWS IaC
    Hook settings.json의 hooks 모델이 아니라 Claude Code가 실행 반드시 지켜야 하는 규칙을 코드로 강제 리전 없는 aws 명령 차단
    Plugin /plugin으로 설치 묶음에 따라 위 확장을 묶어 팀에 배포 Lab 6 참고

    Info

    CLAUDE.md의 규칙은 모델이 따르려고 노력하는 것이고, hook과 permissions는 반드시 적용됩니다. "절대 안 되는 것"은 hook·deny로, "이렇게 하면 좋은 것"은 CLAUDE.md로 둡니다.

    2. Skill¶

    Skill은 폴더 하나에 SKILL.md(앞부분에 name, description)와 필요한 템플릿·스크립트를 둔 것입니다. Claude는 description을 보고 지금 작업에 맞는 skill을 스스로 불러오며, 사용자가 /net-test-plan처럼 이름으로 직접 부를 수도 있습니다.

    ---
name: net-test-plan
description: AWS 네트워킹 신규 기능의 테스트 계획서를 docs/test-plan-<기능>.md로 작성합니다. 새 기능 테스트, 검증 계획, 테스트 매트릭스, PoC 계획을 원할 때 사용합니다.
---
# 신규 네트워킹 기능 테스트 계획서
## 절차
1. 조사: AWS 문서(MCP aws-knowledge)로 공지·가이드·API·CFN 속성·리전·쿼터를 확인 …
## 템플릿
…
    • description이 핵심입니다. "무엇을 하는지 + 언제 쓰는지"를 사용자가 말할 법한 단어로 씁니다.
    • 예전의 .claude/commands/*.md(사용자 정의 slash command)도 계속 동작하지만, 지금은 skill로 통일되어 같은 /이름으로 불립니다. 이 워크숍은 skill로 통일합니다(템플릿 파일을 같은 폴더에 함께 둘 수 있기 때문).

    3. Subagent¶

    Subagent는 자기만의 시스템 지시·도구·컨텍스트를 가진 보조 에이전트입니다. 메인 세션은 subagent의 최종 보고만 받으므로 컨텍스트가 깨끗하게 유지됩니다.

    ---
name: net-reviewer
description: AWS 네트워킹 테스트 계획서, CloudFormation 템플릿, 테스트 스크립트, 워크숍 페이지를 독립적으로 리뷰합니다.
tools: Read, Grep, Glob, Bash
model: inherit
---
당신은 AWS Networking 전문 리뷰어입니다. 작성자의 설명·가설은 근거로 삼지 않고, 리뷰 대상 경로와 관점만 받아 파일을 직접 읽어 판단합니다. 파일을 고치지 않습니다. …
    • 독립 리뷰의 원칙: 리뷰어에게 "내가 이렇게 고쳤으니 맞는지 봐 줘"라고 하면 작성자의 가설을 확인해 주는 쪽으로 기웁니다. 대상과 관점만 넘깁니다(Lab 6).
    • /agents로 목록을 보고 새 subagent를 만들 수 있습니다.

    4. MCP 서버¶

    MCP(Model Context Protocol)는 Claude Code에 외부 도구를 붙이는 표준입니다. Networking SA에게 가장 유용한 것은 AWS 공식 문서 검색입니다. 모델이 학습한 뒤에 나온 신규 기능(예: 2026년 11월의 NLB mTLS)은 문서를 직접 읽어야 정확합니다.

    starter kit의 .mcp.json(프로젝트 범위, git 공유):

    {
  "mcpServers": {
    "aws-knowledge": { "type": "http", "url": "https://knowledge-mcp.global.api.aws" },
    "aws-iac": {
      "type": "stdio", "command": "uvx",
      "args": ["awslabs.aws-iac-mcp-server@latest"],
      "env": { "FASTMCP_LOG_LEVEL": "ERROR" }
    }
  }
}
    서버 제공 기능 인증
    aws-knowledge (원격 HTTP) AWS 문서·What's New·블로그 검색과 읽기, 리전 가용성 필요 없음
    aws-iac (로컬 uvx) CloudFormation 검증(cfn-lint)·규정 검사(cfn-guard), 배포 실패 진단, CDK 문서 진단 기능은 로컬 AWS 자격 증명

    명령으로 추가할 수도 있습니다. -s는 범위(local 기본, project는 .mcp.json, user는 모든 프로젝트)입니다.

    claude mcp add --transport http aws-knowledge https://knowledge-mcp.global.api.aws -s project
claude mcp list

    Info

    .mcp.json으로 들어온 프로젝트 서버는 처음 쓸 때 사용 승인을 묻습니다. 세션에서 /mcp로 연결 상태를 확인합니다.

    5. Hook¶

    Hook은 특정 시점(도구 실행 전 PreToolUse, 실행 후 PostToolUse, 세션 시작 등)에 Claude Code가 실행하는 셸 명령입니다. starter kit은 Bash 도구 실행 전에 guard-aws.sh를 부릅니다.

    {
  "hooks": {
    "PreToolUse": [
      { "matcher": "Bash",
        "hooks": [ { "type": "command", "command": "\"$CLAUDE_PROJECT_DIR\"/.claude/hooks/guard-aws.sh" } ] }
    ]
  }
}

    guard-aws.sh는 stdin으로 받은 JSON의 tool_input.command를 읽어

    • 리전 없는 aws 명령(전역 서비스 iam·sts·organizations·route53 제외) → exit 2로 차단. stderr 메시지가 Claude에게 전달되어 Claude가 --region을 붙여 다시 시도합니다.
    • delete-, terminate-, deregister-, revoke- 등 파괴적 명령 → permissionDecision: "ask"를 출력해 사용자에게 다시 묻습니다.
    # hook 단독 테스트
echo '{"tool_name":"Bash","tool_input":{"command":"aws ec2 describe-vpcs"}}' | .claude/hooks/guard-aws.sh; echo "exit=$?"

    미니 실습 (7분)¶

    1. 세션에서 /mcp를 실행해 aws-knowledge를 승인하고 연결을 확인합니다.
    2. Claude Code에 입력:
    aws-knowledge MCP로 Network Load Balancer의 mutual TLS 지원 공지를 찾아서, 발표일과 지원 모드, 문서 URL만 알려 줘.
    1. hook 동작 확인. Claude Code에 입력:
    aws ec2 describe-vpcs 를 --region 없이 그대로 실행해 봐.
    1. /agents에서 net-reviewer가 보이는지, 슬래시(/)를 입력했을 때 net-test-plan이 보이는지 확인합니다.

    검증 체크포인트

    • 2번 답에 문서 URL이 있고, 그 URL을 열었을 때 내용이 일치합니다.
    • 3번에서 hook이 명령을 막고, Claude가 --region ap-northeast-2를 붙여 다시 실행합니다.
