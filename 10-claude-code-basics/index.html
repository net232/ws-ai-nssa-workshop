    1. Claude Code 기초¶

    이 모듈에서는 Claude Code를 질문에 답하는 대화창이 아니라, 규칙과 도구를 갖춘 작업 환경으로 쓰는 방법을 익힙니다. 뒤의 실습(Lab 1–6)은 모두 여기서 만든 설정 위에서 진행합니다.

    왜 "작업 환경"인가¶

    프롬프트만으로 쓰면 매번 같은 설명을 반복하게 됩니다. "리전은 ap-northeast-2", "태그를 붙여라", "삭제 전에 물어봐라", "문서로 확인해라". 사람에게 새 팀원이 오면 온보딩 문서와 권한을 주듯, Claude Code에도 다음을 미리 줍니다.

    사람 팀원에게 주는 것 Claude Code에서 이 모듈의 페이지
    업무 규칙·온보딩 문서 CLAUDE.md, AGENTS.md 1-2
    계정 권한, 승인 절차 settings.json의 permissions, 권한 모드 1-3
    업무 매뉴얼·체크리스트 Skills 1-4
    리뷰를 맡길 동료 Subagents 1-4
    외부 문서·도구 연결 MCP 서버 (AWS 문서, IaC 도구) 1-4
    안전 장치 Hooks 1-4

    Claude Code의 구성 요소¶

    • ① 컨텍스트는 세션을 시작할 때 자동으로 읽힙니다. 항상 지켜야 할 규칙을 둡니다.
    • ② 확장은 필요할 때만 불러 씁니다. 긴 절차나 특정 작업에만 필요한 지식을 둡니다. 컨텍스트를 아끼는 방법이기도 합니다.
    • 모델은 생각 → 도구 호출 → 결과 확인을 반복하는 에이전트 루프로 일합니다. 도구 호출은 권한 설정과 hook을 거쳐 실행됩니다.

    진행 순서 (약 90분)¶

    페이지 내용 시간
    1-1 첫 세션 Bedrock 연결, 기본 조작, slash command, 권한 모드, plan mode 20분
    1-2 CLAUDE.md와 AGENTS.md 메모리 계층, 좋은 규칙 쓰기, starter kit 적용 20분
    1-3 설정과 권한 settings.json, allow/ask/deny, 안전 수칙 10분
    1-4 확장: Skill·Subagent·MCP·Hook 언제 무엇을 쓰는지, AWS MCP 연결 15분
    1-5 실전 팁 좋은 프롬프트, 컨텍스트 관리, 환각 대처 10분
    1-6 Matt Pocock skills 활용 남이 만든 skill 써 보기: /grill-me, /research, diagnosing-bugs, /handoff 15분
