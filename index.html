    AI로 일하는 Networking SA — Claude Code로 신규 기능 테스트와 워크숍 만들기¶

    신규 네트워킹 기능이 나오면 Networking Specialist SA는 문서를 읽고, 테스트 환경을 만들고, 기대대로 동작하는지 확인하고, 그 결과를 고객 워크숍이나 데모로 만듭니다. 이 워크숍에서는 이 과정 전체를 Claude Code와 함께 진행합니다.

    강사가 실제로 했던 두 가지 작업을 재현합니다.

    • 신규 기능 테스트: 2026년 11월에 출시된 Network Load Balancer mutual TLS(mTLS)를 조사하고, 테스트 매트릭스를 설계하고, 배포해서 검증하고, 장애를 진단합니다.
    • 워크숍 제작: Transit Gateway → AWS Cloud WAN 마이그레이션 워크숍의 한 모듈을 기획부터 IaC, 페이지, 구성도까지 만듭니다.

    대상과 사전 지식¶

    • AWS Networking Specialist SA 또는 VPC, Transit Gateway, ELB, CloudFormation을 실무에서 다루는 분
    • Claude Code에 프롬프트를 몇 번 입력해 본 정도면 충분합니다. 설정 파일, skill, subagent, MCP는 Module 1에서 처음부터 다룹니다.

    이 워크숍을 마치면¶

    1. Claude Code를 대화창이 아니라 작업 환경으로 설정할 수 있습니다. 여기에는 CLAUDE.md, AGENTS.md, 권한, skill, subagent, MCP, hook이 포함됩니다.
    2. 신규 기능 테스트와 워크숍 제작의 라이프사이클 8단계를 AI와 함께 끝까지 진행할 수 있습니다.
    3. AI가 만든 결과물을 검증할 수 있습니다. 문서와 대조하고, lint를 돌리고, 실제로 배포해 측정하고, 독립 리뷰를 받습니다.
    4. 반복하는 작업을 skill로 만들어 다음 기능 테스트에 다시 씁니다.

    Lab 1–4는 하나의 테스트(NLB mTLS)를 이어서 진행합니다. 앞 Lab의 산출물을 다음 Lab에서 사용하므로 순서대로 진행하세요. 막히면 각 Lab의 정답 참고 펼침 상자나 정답 자료(~/ws-solutions, 0. 환경 준비에서 받음)를 사용합니다.

    비용¶

    실습 계정에 생기는 주요 리소스는 Workshop IDE용 EC2(t4g.medium), NAT gateway 1개, NLB 1개, EC2 3대(t4g.micro)이며, Lab 5에서는 선택 사항으로 Cloud WAN core network가 추가됩니다. 워크숍 하루 동안의 비용은 Lab 5의 선택 배포를 제외하면 수 달러 수준입니다. Claude Code의 Amazon Bedrock 사용량은 별도로 청구됩니다. 실습이 끝나면 반드시 정리를 진행하세요.

    원칙: AI는 초안을 만들고, 판단과 책임은 사람에게 있다¶

    이 워크숍의 모든 Lab에는 검증 체크포인트가 있습니다. AI는 존재하지 않는 CloudFormation 속성이나 API 파라미터를 그럴듯하게 만들어 낼 수 있습니다. 출처 URL, cfn-lint, 실제 배포 결과, 독립 리뷰로 확인한 내용만 다음 단계로 넘깁니다.
